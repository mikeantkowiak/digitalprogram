Hive Media Group

Influencer Dashboard

Project Overview

Hive Media Group needed a tool to visualize and present data to both the influencers and account managers. The main capabilities of the dashboard were to allow influencers to view post data, earning reports and historical data in an intuitive user experience. An integrated CRM feature for account managers was implemented to view associated influencers and statistics, generate historical data and revenue earning reports.

Technical Environment

  • Backend: AWS, Ubuntu, Laravel Forge, Laravel 5

  • Front-end: Design and Mockups, Custom SCSS and Bootstrap 3, gulp for compiling

  • Javascript: Custom integrations of DataTables.js and Chart.js

  • Version Control: BitBucket

Living Style Guide

After the initial designs were created and confirmed, the HTML, CSS and base js front-end frameworks were coded, customized and placed on a static website and kept in a independent git repository. The goal was to separate the design front-end presentation layer from the backend layer for easier updates to overall branding, UI elements, and reusable components.

Technical Environment

  • SCSS Framework: Bootstrap 3

  • Front-end: HTML, Datatables.js, Chart.js
